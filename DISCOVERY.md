# Workstation Repository Discovery

## Source Repository

dotfiles / nextgen-workstation

---

## High-Level Summary

The legacy repository evolved over multiple years from a personal dotfiles repository into the prototype for the Engineering Workstation.

As a result, it contains a mixture of:

- workstation provisioning
- shell configuration
- package management
- engineering experiments
- AI tooling
- temporary utilities
- historical artifacts

The purpose of this discovery is to inventory the repository prior to migration.
